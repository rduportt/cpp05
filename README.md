# CPP Module 05

> Repetition and exceptions.

## What's inside

- try / catch and custom exception classes
- Bureaucrat and Form
- Concrete forms: Shrubbery, Robotomy, Presidential Pardon
- Intern

## Usage

```bash
cd ex00      # pick an exercise (ex00, ex01, ...)
make
./<executable>
```
Each exercise has its own Makefile and is compiled with `c++ -Wall -Wextra -Werror -std=c++98`.
